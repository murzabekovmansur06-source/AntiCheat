# 🛡️ AntiCheat for Roblox (Racing Edition)

Полностью рабочий серверный античит для гонок и других игр. Защищает от спама ремоутов, полёта, флайкаров, бесконечных прыжков и speed hack.

## 📋 Возможности

| Защита | Описание |
|--------|----------|
| Спам RemoteEvent | Блокирует повторные вызовы чаще лимита |
| Полёт (Fly) | Телепортирует на землю при длительном полёте |
| Флайкар | Обнаруживает и опускает летающие машины |
| Бесконечные прыжки | Ограничивает частоту и количество прыжков |
| Speed Hack | Блокирует аномально быстрое падение |

## 🚀 Как установить

1. Скачай файл `AntiCheat.lua`
2. Помести его в `ServerScriptService`
3. Пометь трамплины тегом `RampZone` (через вкладку Tags в свойствах детали)
4. Настрой параметры под свою карту в блоке `CONFIG`

## ⚙️ Настройка

В начале скрипта есть блок `CONFIG` — все настройки там:

local CONFIG = {
    RemoteCooldown = 0.4,              -- секунд между вызовами одного ремоута
    MaxRemoteCallsPerSecond = 25,      -- общий лимит вызовов в секунду
    WhitelistedRemotes = {},           -- точные имена ремоутов без проверки
    MaxAirTime = 8.0,                  -- макс. секунд в воздухе
    JumpCooldown = 0.6,                -- секунд между прыжками
    MaxConsecutiveJumps = 5,           -- макс. прыжков подряд
    MaxVehicleHeight = 100,            -- макс. высота машины
    MaxFallSpeed = -80,                -- скорость падения (speed hack)
    VehicleCheckInterval = 0.5,        -- проверка машин раз в N секунд
    PlayerCheckInterval = 0.3,         -- проверка игроков раз в N секунд
    RampCheckInterval = 1.0,           -- проверка трамплинов раз в N секунд
}

## 🏎️ Особенности для гонок

- Нет ограничения скорости (машины могут ездить быстро)
- Трамплины игнорируются (помечай их тегом RampZone)
- Проверка вертикальной скорости (не телепортирует если машина падает)
- Настраиваемая высота полёта для машин
- Кэширование проверок для производительности

## 🔧 Как работает защита ремоутов

Античит перехватывает все RemoteEvent через OnServerEvent:
1. Отключает старые обработчики
2. Проверяет лимиты вызовов
3. Если спам — блокирует
4. Если норма — вызывает оригинальные обработчики

Есть белый список ремоутов которые можно вызывать без ограничений.

## ⚠️ Важно

- Все RemoteEvent должны передавать player первым аргументом
- Машины должны иметь PrimaryPart (или Base/Chassis/Engine)
- Трамплины нужно пометить тегом RampZone
- Античит работает только на сервере (ServerScriptService)
